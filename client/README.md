# Shopping Mall Client

Vite와 React 기반 프론트엔드 앱입니다.

## 시작하기

```bash
cd client
npm install
cp .env.example .env
npm start
```

기본 주소는 `http://127.0.0.1:3000` 입니다.

## 스크립트

- `npm run dev`: 개발 서버 실행
- `npm start`: 개발 서버 실행
- `npm run build`: 프로덕션 빌드
- `npm run preview`: 빌드 결과 미리보기
- `npm run lint`: ESLint 검사
