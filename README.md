# STRIDE Shopping Mall Project

STRIDE는 다양한 브랜드의 신발을 탐색하고 구매할 수 있는 온라인 쇼핑몰 웹 서비스입니다. 회원가입, 상품 조회, 장바구니, 결제, 주문 관리 기능을 제공하며, 관리자는 전용 페이지에서 상품·재고·주문·회원·브랜드·배너를 관리할 수 있습니다.

## 개발 기간

- 2026.08.05 ~ 2026.08.14(10일)

## 배포 링크
배포 URL: [STRIDE 서비스 바로가기](https://vibe-coding-shopping-mall-kappa.vercel.app/)

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | JavaScript, React 19, React Router DOM 7, Vite 8, CSS, Lucide React, Fetch API |
| 백엔드 | Node.js, Express 4, Mongoose 8, JSON Web Token, bcrypt |
| 데이터베이스 | MongoDB |
| 외부 API / 서비스 | PortOne V1, Solapi, Kakao / Daum 우편번호 서비스 |
| 배포 | Vercel (프론트엔드), Heroku (백엔드) |


## 주요 기능

**사용자 기능**
- 회원가입 및 JWT 기반 로그인
- 상품 검색·필터링, 장바구니 및 찜 관리
- 주문·결제·취소 및 주문 내역 조회
- 리뷰 작성 및 상품 문의

**관리자 기능**
- 매출·주문·재고 통계 대시보드
- 상품·브랜드·배너 및 재고 관리
- 주문 상태 및 회원 관리 <br>
